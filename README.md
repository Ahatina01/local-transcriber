# Локальная расшифровка

## Запуск

Дважды нажмите **Запустить.cmd** в этой папке. Откроется браузер с адресом http://127.0.0.1:8765. Интернет для обработки не нужен.

1. Сохраните голосовое из Telegram как файл, затем перетащите его в окно программы или нажмите «Выбрать аудиофайл».
2. Дождитесь распознавания и подготовки конспекта. Не выключайте компьютер во время обработки.
3. Результаты автоматически появляются в **results**. Каждая запись получает отдельную папку. Кнопки «Сохранить TXT» и «Сохранить Markdown» позволяют дополнительно скачать копию через браузер.
4. Для остановки нажмите **Закрыть программу** внизу страницы. Простое закрытие вкладки оставляет программу работающей; повторный запуск откроет её снова.

**TXT** — полная расшифровка. **Markdown** — содержание, тезисы, задачи/сроки и полная расшифровка. Если Qwen недоступна, уже распознанный текст остаётся в results. Исходный аудиофайл не изменяется. Временная копия удаляется после обработки; при аварийном завершении она может остаться в temp.

Задачи и тезисы выводятся с дословными цитатами, которые программа сверяет с расшифровкой. Это помогает обнаруживать ошибки модели, но не гарантирует, что все поручения будут найдены или что сама расшифровка безошибочна. Краткое содержание остаётся автоматически составленным текстом.

## Что используется

- Существующие Python и библиотеки из `%APPDATA%\open-webui\python`. Не удаляйте эту папку: приложение использует её, но не требует запуска Open WebUI Desktop.
- Whisper large-v3: локальные файлы в `models/whisper-large-v3`, около 3,1 ГБ. Работа на CPU, int8, четыре потока.
- Локальная `qwen3:4b-instruct` (Q4_K_M) для конспекта.
- Собственный экземпляр существующей Ollama на `127.0.0.1:11435`. Он запускается с `OLLAMA_NO_CLOUD=1` и завершается вместе с программой. Уже работавшая Ollama на 11434 не менялась.

## Приватность

Аудио декодируется и распознаётся на компьютере. Только текст передаётся в локальную Ollama. Внешних API, облачных моделей, CDN, аналитики и автоматической загрузки моделей в приложении нет. Python работает с офлайн-переменными Hugging Face/Transformers; внешние подключения и DNS-запросы Python блокируются обработчиком аудита. Декодер ограничен аудиоконтейнерами и локальными протоколами. Интерфейс слушает только 127.0.0.1, проверяет Host, Origin и токен сеанса.

Это ограничения приложения, а не системный межсетевой экран для всех программ Windows. Для физически изолированного режима можно отключить интернет после запуска: модели уже сохранены. Результаты — обычные незашифрованные локальные файлы. Расширения вашего браузера и синхронизация папок управляются отдельно от приложения.

## Ограничения

- Один файл за раз, до 512 МБ. Проверены WAV, MP3 и OGG/Opus. Также доступны M4A, FLAC, OPUS, MP4, MKV, MOV, AVI и WebM со звуковой дорожкой.
- Для длинных записей конспекты формируются по частям, примерно по 6000 символов; полный текст не обрезается. Единый итог для многочасовых записей не формируется.
- Автоматическое распознавание не гарантирует абсолютную точность. Проверяйте имена, числа, суммы и сроки по исходной записи. Перекрывающиеся голоса и шум ухудшают результат. Идентификация говорящих не реализована.
- В процессе Whisper и Qwen запускаются последовательно для экономии памяти. Скорость зависит от длины записи и свободной RAM. Длинная реальная встреча в этой настройке ещё не тестировалась.
- Если переносите папку на другой компьютер, потребуются указанные Python-библиотеки, Ollama и модели. Это настроенное приложение для текущего компьютера, не автономный установщик.
- Ошибки запуска: `logs/launcher.log`; работа Ollama: `logs/ollama.log`. Порты 8765 и 11435 должны быть свободны.

## Настройка на другом компьютере

Нужны Windows, Python 3.12 с faster-whisper и PyAV, Ollama, локальная модель `qwen3:4b-instruct` и файлы `Systran/faster-whisper-large-v3` в `models/whisper-large-v3`.

Каталог движка задаётся переменной `TRANSCRIBER_RUNTIME` или файлом `settings.local.json` рядом с программой:

```json
{"runtime_dir": "D:/LocalAI/runtime"}
```

Внутри него ожидаются `ollama/ollama.exe` и `ollama-models/`. По умолчанию используется `.local-transcriber/runtime` в домашней папке. Локальная конфигурация исключена из Git. Запуск через `Запустить.cmd` использует среду Python, установленную Open WebUI; при другой установке запускайте `launcher.py` своим Python.

Модели и зависимости скачиваются отдельно при настройке. При обычной работе автоматические загрузки отключены. Обработка видео использует встроенные библиотеки FFmpeg через PyAV: видеокадры не анализируются, распознаётся только звуковая дорожка.
